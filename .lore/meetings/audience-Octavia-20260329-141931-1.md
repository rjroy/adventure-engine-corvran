CORVRAN SYSTEM LOADING BRAINSTORM
Meeting: 2026-03-30

Session resolved all seven open questions in the RPG system loading brainstorm. The design establishes how game systems (d20, Daggerheart, freeform) are declared per-adventure, loaded conditionally, and bootstrapped into the AI's prompt context.

Core decisions: Adventures declare their system in a single `system` field in `adventure.md`. Only one system plugin loads per adventure, plus corvran core. Plugins self-describe via `corvran-plugin.json` manifest files scanned at startup. Bootstrap prompts are well-structured markdown authored by system maintainers, inserted into the system prompt's Identity section to establish the AI's mental model before any skill invocation. Adventures without `adventure.md` default to freeform (corvran-only, pure narrative). Plugin paths remain repo-relative; no environment configuration needed.

Significant scope addition: the dice roller (previously a corvran skill) becomes an engine-provided MCP tool accepting grouped rolls with labels, optional modifiers, and optional thresholds. The tool returns pre-computed results and threshold checks, removing all arithmetic from the AI's responsibilities. System plugins no longer depend on corvran, eliminating fragile relative path references.

Artifacts produced: brainstorm/rpg-system-loading.md marked resolved. Document captures manifest schema, bootstrap prompt anti-patterns, adventure.md format, and complete plugin loading architecture. Ready for spec commission.

Follow-up: Commission a spec defining `adventure.md` format, `corvran-plugin.json` manifest schema, bootstrap prompt conventions, dice tool MCP contract, and changes to plugin resolution and session runner architecture. User to initiate when ready.
