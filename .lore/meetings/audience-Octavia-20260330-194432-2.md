**Meeting Notes: Audience with Octavia**
**Project:** Corvran | **Date:** 2026-03-31 | **Artifact:** .lore/research/dynamic-color-palettes.md

**Summary**

Octavia reviewed Verity's research on dynamic color palette generation from seed colors for the GM mood system. The research foundations are sound: OKLCH color space (perceptually uniform, CSS-native, stable across hues), culori/fn library (tree-shakeable, OKLCH-native, includes contrast calculation), tonal palette approach (fixed-lightness steps with mechanical contrast enforcement), and prior art validation across Spotify, Material You, and other systems. The document correctly establishes why this approach is superior to HSL harmony calculations and documents the tradeoffs between library options comprehensively.

A critical implementation gap was identified in the example code. The code sketch assumes light-mode UI (near-white backgrounds at L:97%, near-black text at L:12%) but Corvran's actual UI is dark-mode with warm amber text on cool indigo backgrounds (L:20-30% backgrounds, L:45-90% text). Beyond inverted lightness, the research doesn't address Corvran's multi-hue structure: indigo for backgrounds, amber for primary accents, plus additional semantic roles (GM accent, player accent, tool events, error/stop). The research would have guided someone to build the wrong palette generator if copied directly.

**Decisions**

Flag the implementation sketch as having context-specific gaps. Add a clear warning before the code example pointing implementers to globals.css as the source of truth for Corvran's actual variable structure and role assignments. Preserve the research findings and methodology (all sound) while preventing copy-paste misapplication.

- `.lore/research/dynamic-color-palettes.md` — updated with gap annotation before Implementation Sketch section

**Follow-ups**

Next step when implementing: write a spec that maps the research methodology onto Corvran's actual palette structure (dark-mode, multi-hue, semantic roles), then provide concrete code tailored to that structure rather than a generic example.
